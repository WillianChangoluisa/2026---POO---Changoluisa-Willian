# Semana 14 - Componentes y contenedores

En esta semana se evoluciona la aplicación `restaurante_app` integrando componentes, contenedores y una interfaz más clara para gestionar productos y consultar usuarios.

La estructura principal está en la carpeta `restaurante_app/` y mantiene la separación entre modelos, servicios, interfaz y persistencia en JSON.

## Ejecución

```bash
cd "Parcial 2/Semana 14"
python restaurante_app/main.py
```
